## 2. 已确定的产品基线

1. 服务希望通过知识科普视频深化学习、积累公开作品资产的大学生。
2. 只有知识挑战、视频复盘两个核心模式，二者可独立使用，共享“我的知识作品”。
3. 挑战流程包括选领域、基础、时间预算、抽题、自主学习、独立解释、AI 追问和反馈、知识修正、脚本、保存；分镜可选。
4. 复盘流程包括视频上传、FFmpeg 提取音频、开源 ASR 带时间戳转写、用户核对、AI 反馈与追问、保存；支持同知识点挑战与视频关联。
5. 反馈必须分清可验证事实、合理推断、待核实判断。AI 评价不是事实核查结果，完成视频不是掌握证明。
6. 优先 Python、Streamlit、SQLite、大模型 API、FFmpeg、成熟开源 ASR，避免多服务架构。
7. 先交付中文 Markdown 文档，待用户审核后才编码。

## 3. 建议 MVP 参数（未获确认）

| 项目 | 建议值 | 设计依据 / 调整影响 |
| --- | --- | --- |
| 部署 | Windows 单机、单用户、仅本机访问 | 不承担多租户隔离、公网运营 |
| 语言 | 普通话视频、简体中文交互 | 混合语言转写只作尽力处理并提示核对 |
| 知识库 | 概率统计、AI 基础，共 12 个经人工审核的知识点，建议每类 6 个 | 先保证资料与纠错可解释，审核不完则缩减题库并记录 |
| 基础 | 入门 / 学过基础 / 较熟悉 | 自报标签，不视作测评结果 |
| 学习预算 | 15 / 30 / 60 分钟 | 是任务适配参数，不是倒计时或视频长度 |
| 输入长度 | 独立解释、修正各 1–6000 字符；单题回答 1–2000 字符 | 去空白后校验，短于 50 字可提示补充，不强制拒绝 |
| 追问 | 一轮 1–3 题，可逐题回答或明确跳过 | 不做无限对话；跳过产生证据缺口 |
| 挑战 AI 调用 | 追问、反馈、修正复核、脚本，至多 4 个逻辑步骤 | 同一请求重试不新增记录；允许保存任何阶段草稿 |
| 脚本 | 目标 60–120 秒；可编辑 Markdown | 时长是估计；只使用复核后可表达内容，未决主张排除或显著标注 |
| 视频 | MP4 / MOV / WebM；0 < 文件大小 ≤ 100 MiB（104857600 字节）；0 < 时长 ≤ 300 秒 | 扩展名不代表可解码；ffprobe 实测后判断，演示用 30–90 秒短片 |
| 音频 | FFmpeg 转单声道、16 kHz、PCM WAV | 原视频时间轴起点归零；不可切静音后重新编号时间 |
| ASR | faster-whisper `small`，CPU `int8` 为首选候选 | D0 在实际设备测试；达不到目标可评测 `base`，不得静默换模型 |
| 转写核对 | 按段编辑文字，保留段 ID 和起止毫秒；确认完整版本后复盘 | P0 不做手工时间轴编辑和逐词对齐 |
| AI 输出 | 协议 v1.0，严格 JSON，结构与引用双校验 | 非法输出不当作成功，不显示模型伪造的“已核实”状态 |
| 默认来源 | 本地人工审核来源包、用户提供的可定位文本 | P0 不做开放网页抓取、全网核查、向量数据库 |
| 视频内容留存 | 原视频存本地作品目录；临时音频任务结束清理 | 用户可删媒体保留记录；完整删除需同步删除本地派生文件 |
| 网络数据 | 仅经用户同意发送所需文字与来源片段至所选模型 API | 原视频和音频不发给云端大模型；服务商策略待选择后披露 |
| 长任务 | 单机同一时刻最多一个重任务；明确提交才执行 | 刷新不可重复扣费，启动时将遗留运行任务标记为中断 |
| 超时 | ffprobe 15 秒；FFmpeg 120 秒；ASR 600 秒；单次 LLM 60 秒 | 可配置；LLM 最多额外重试 1 次，含格式修复，总等待上限 125 秒 |
