## 启动

直接双击 `index.html`（零构建、零依赖、零网络请求），或在本目录起任意静态服务器。

## V1 / V2 对比（页内「V1 原版 / V2 质感升级」切换，布局尺寸完全一致）

| 维度 | V1 | V2（2026-10-18） |
| --- | --- | --- |
| 火舌运动 | 每舌整体 CSS 呼吸动画（独立周期但仅缩放+微摆） | **多谐波逐舌驱动**：每舌两个不可通约频率的尖端摇摆 + 低频伸缩 + 同源横移，相位确定性错开；焰心小反相摆（更克制）；根部锚定不动 |
| 亮度层次 | 三层渐变静态分配 | 外焰/内焰/焰心分层节奏：内焰亮度随 fireIntensity 上升、焰心透明度联动；全局 9s 慢呼吸 |
| 环境辉光 | 静态 radial 光晕随等级变化 | 增加 **11s 低频呼吸**（--breath 系数），锁定时一次性 glow 脉冲（650ms，仅触发一次） |
| 余烬 | 无 | **两方案共享的 canvas 余烬层**（上限 26）：沿外缘上弧生成，慢速上浮 + 正弦横摆 + 缩小淡出；待机 ~1 颗、抽题 ~5 颗 |
| 抽题联动 | fireIntensity 平滑升腾/收敛 | 同左（复用同一 lvl 状态机），外焰升高、内焰增亮、余烬频率随 fireIntensity 增加 |

V1 代码路径保留未删——切换按钮即回退开关。

## 三态设计（对齐参考图）

| 状态 | 火焰 | 罗盘环 | 指针 |
| --- | --- | --- | --- |
| 待机 | 微弱呼吸燃烧（fireIntensity 0.25），余烬偶现 | 暗红细环 | 22°/s 慢转 |
| 抽题中 | 平滑升腾后随减速收敛（峰值 ~1.1），火舌加快 | 亮橙加粗 | 速度与词条切换间隔成反比（300→45°/s） |
| 锁定 | 短促暖色亮起 + 一次性外缘光效，~340ms 后回落微燃 | 暖金加粗 | 指数缓停至静止 |

## 参数控制表

| 参数 | 控制对象 |
| --- | --- |
| `fireIntensity`（状态机内部） | 火焰 scaleY/opacity、内焰亮度、余烬生成率、辉光强度；待机 0.25 → 抽题峰值 ~1.1 → 锁定回落 |
| 强度滑条（20–100%） | 余烬/粒子生成率与粒子尺寸 |
| 速度滑条（0.5–2.0×） | V1 CSS `--d` 周期；V2 谐波时间步与粒子时间步 |
| 动效开关 | 停 rAF + 冻结一帧完整静态视觉（V2 形态固化） |
| 方案 A/B | SVG 火焰 / canvas 粒子；余烬层共享 |

## 性能与生命周期

单 rAF 循环（无竞争任务）；`document.hidden` 时暂停、恢复可见续跑；pagehide 清理全部定时器与 rAF；余烬/粒子上限池（26/90）；谐波长 PER 帧仅 9 组 transform 写入（无 DOM 重建、无每帧随机坐标）；SVG 模糊滤镜静态（stdDeviation 2.6，不做逐帧滤镜）；动画层 `pointer-events:none` 不挡点击；reduced-motion 自动静态。
