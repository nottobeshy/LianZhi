## 5. 三分钟双模式演示（180 秒）

演示目的：让评审看见“独立解释 → 追问与修正”以及“核对转写 → 有位置的复盘”是不同入口，最终进入同一作品档案。主线用一个经审核知识点，例如“相关不等于因果”。现场只演示已通过测试的能力。

演示材料应包括一份原始解释、一处典型误解、一份修正稿、一段 30–60 秒授权视频及其人工核对稿。所有姓名、片段与报告使用可公开样本，不使用未获授权的个人内容。

### 演示回退与答辩准备

- **现场 API 失败：** 保留错误状态，展示同版本的已保存报告，明确“这是此前生成的结果；当前网络调用失败”。不要求评审等待重试，不把旧结果套在新输入上。
- **ASR 超过演示窗口：** 用固定演示视频展示真实历史任务的模型/时间记录，或播放实际录屏；显示该段为录屏/预生成。现场仍可查看和修改转写，但不声称刚刚完成整段转写。
- **媒体无法播放：** 使用授权备用短片或已经导出的文字报告；说明失效环节，并在测试记录中登记，不把回退当成原功能通过。
- **离线演示：** 本地档案、历史报告和 PPT 可用。没有云模型请求就不要声称本次现场已得到新 AI 分析。
- **常见追问准备：** 为什么不是脚本生成器；怎样处理错误知识和伪引用；为什么先核对转写；如何保护用户视频；何种证据才能支持“理解有改善”；单机版如何扩展但尚未做什么。
